🟥 Quiz Game

A simple multiple-choice quiz game written in Python. This project was created as a beginner programming exercise to practice loops, conditions, tuples, lists, user input, and score calculation.

🔷 Features

- Multiple-choice questions
- Four answer options (A, B, C, D)
- Answer validation (basic)
- Automatic answer checking
- Correct answer display
- Score calculation
- Final results summary

🔷 Concepts Used

- Variables
- For loops
- Nested loops
- Tuples
- Lists
- If / else statements
- Indexing
- User input
- String methods (.upper())
- Arithmetic operators
- Score calculation

🔷 How It Works

The program displays a series of multiple-choice questions.

Each question has four possible answers:

- A
- B
- C
- D

The user enters their chosen answer.

The program compares the user's guess with the correct answer:

- If the answer is correct, the score increases by 1.
- If the answer is incorrect, the correct answer is displayed.

After answering all questions, the program displays the final results.
